# 학원 메인 컬러 안내 (설명회 슬라이드 키트)

설명회 슬라이드는 디자인이 고정이고, 학원마다 바뀌는 건 **메인 컬러 하나**입니다. 원장님이 학원 설정에서 고른 색이 `?brand=#RRGGBB`로 들어오면 `slide/main.js applyBrand`가 슬라이드 전체에 적용합니다. 이 문서는 어떤 색이 어떻게 처리되는지, 그리고 **검정 · 회색 계열 학원 색**의 한계와 권장 안내를 정리합니다. (2026-10-23, 덱 24개 × 여러 학원 색 점검 뒤 작성)

## 1. 색이 처리되는 방식

| 학원 색 | 예 | 키트가 하는 일 |
|---|---|---|
| 어둡거나 중간 밝기 | 파랑 #2F5BEA · 빨강 #E03E3E · 보라 #7C3AED · 청록 #0D9488 · 남색 #1E3A8A | 그대로 씀. 메인 면 위 글자는 흰색 |
| 밝은 색 (흰 글자 대비 3 : 1 미만) | 노랑 #FACC15 · 연두 #84CC16 · 하늘 #38BDF8 · 민트 #10B981 | 그대로 쓰되 메인 면 위 글자 · 체크를 **진한 색**으로, 흰 바탕 위 강조 글자를 회색 판과 4 : 1이 될 때까지 **진하게 섞은 색**으로 |
| 아주 밝은 파스텔 (상대 밝기 0.62 넘음) | 연노랑 #FDE68A · 연분홍 #FBCFE8 · 연하늘 #BAE6FD | **같은 색상 · 채도로 밝기만 낮춰** 씀(연노랑 → 진한 노랑). 그다음은 '밝은 색'과 같음 |
| 거의 흰색 (채도 10% 미만 + 아주 밝음) | #F8F8F8 · #FFFFFF | 메인으로 쓸 수 없어 **기본 파랑(#2F5BEA)** 유지 |
| 검정 · 회색 계열 | #111827 · #374151 · #6B7280 · #9CA3AF | 그대로 씀 — **아래 2번의 한계가 있음** |

- 메인 면 위 번호 동그라미 · 막대 같은 칠한 조각은 학원 색과 상관없이 흰색, 장 표지 큰 번호는 흰색을 섞은 옅은 장식입니다.
- 검사(`node scripts/slide-shot.mjs --brand '#색'`)가 글자 뒤 실제 색과 대비 2.5 : 1 미만인 글자를 잡습니다.

## 2. 검정 · 회색 학원 색의 한계

키트의 디자인은 "회색 · 흰색 바탕 위에 **메인 컬러로 한 곳만 강조**"가 기본입니다. 학원 색이 검정이나 회색이면 강조할 색 자체가 바탕 색들과 같은 계열이라 강조가 잘 보이지 않습니다.

- **검정에 가까운 색(#111827 등)**: 강조 글자(표지 제목의 강조 낱말, 큰 숫자, 목차 표시)가 일반 제목 글자(#14161C)와 거의 같은 색이라 **무엇을 강조했는지 구분이 안 됩니다.** 메인 면(강조 카드 · 표지 오른쪽 면)은 검정 면으로 보여 무거워집니다.
- **회색(#6B7280 등)**: 강조 면과 강조 글자가 키트의 보조 회색(설명 글 · 빈 막대)과 비슷해서 **'비활성'이나 '선택 안 됨'처럼 보입니다.**
- 글자가 안 읽히는 문제는 없어서 검사는 통과합니다. 문제는 **강조 효과가 사라지는 것**입니다.

## 3. 홈페이지에 권장하는 안내 (개발자 참고)

키트 쪽에서 검정 · 회색을 다른 색으로 바꾸면 원장님이 고른 색을 무시하게 되므로 자동으로 바꾸지 않습니다. 대신 학원 설정 화면에서 아래처럼 안내하기를 권합니다.

1. **알아보는 법** — 학원 색을 HSL로 바꿨을 때
   - 채도(S) 15% 미만이면 회색 계열
   - 또는 WCAG 상대 밝기 0.03 미만(아주 어두움)이면 검정 계열
2. **안내 문구 예**: "회색 · 검정 계열 색은 설명회 자료에서 강조가 잘 보이지 않아요. 로고에 쓰는 다른 색(포인트 색)이 있다면 그 색을 메인 컬러로 골라 주세요."
3. **고르기 쉽게**: 안내와 함께 추천 색 몇 개(파랑 #2F5BEA · 청록 #0D9488 · 주황 #F06A1D · 보라 #7C3AED)를 보여 주면 좋습니다.
4. 원장님이 그래도 검정 · 회색을 고르면 그대로 씁니다(자료는 정상으로 만들어지고, 강조만 약함).

## 4. 고칠 때

- 학원 색 처리는 `slide/main.js applyBrand` 한곳에서만 바꿉니다. CSS에서 글자색은 `var(--main-text)`, 메인 면 위 글자는 `var(--on-main)`, 칠한 도형 · 별 · 체크 같은 아이콘은 `var(--main)`을 씁니다(CLAUDE.md '설명회 PPT 디자인 규칙' 첫 줄).
- 새 부품을 만들면 밝은 색(`--brand '#FACC15'` · `'#10B981'`)과 파스텔(`'#FDE68A'`)로도 한 번 찍어 봅니다.
