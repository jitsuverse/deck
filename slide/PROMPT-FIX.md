# 걸린 장만 다시 쓰기 (덱을 쓰는 Claude용 — 3단계)

홈페이지가 덱을 그려 검사(`window.slideCheck()`)한 뒤, 문제가 난 장만 이 요청으로 돌려보낸다. 장마다 검사 문장 · 이웃 장 부품 · 지금 HTML이 온다. **그 장들만** 고쳐서 답한다.

## 답 형식

- 고친 장마다 `<!-- N. 단계 — 무엇 -->` 주석 한 줄 + `<section class="slide">…</section>`. N은 받은 장 번호 그대로. 다른 장 · 설명 글 ✗.
- 대제목 · 목차 표시 · 전하는 말은 그대로 두고 도식만 고친다(검사가 대제목 문제를 말할 때만 대제목을 고침).
- 마크업 규칙은 `PROMPT.md` · `PROMPT-PARTS.md` 그대로 — 없는 클래스 ✗, 인라인 글자 크기 · 색 ✗.

## 검사 문장별 고치는 법

| 검사 문장 | 고치는 법 |
|---|---|
| 도식이 작아요 — 본문 영역의 N%만 | 칸을 `w12 h2`로 키우고, 항목 수를 예(`PROMPT-PARTS.md`)와 같게. 그래도 작으면 같은 말을 더 크게 보이는 다른 부품으로 |
| 도식이 칸보다 커서 아래로 넘침 · 내용이 도형보다 커서 넘침 · 콘텐츠 영역 넘침 · 도식이 디자인 영역 아래로 | 글을 줄인다(한 줄 16자 안쪽, 목록 4줄까지), 항목을 하나 줄이거나 문장을 짧게 |
| 머리와 도식 사이 …px (64 이상) | 도식이 너무 커서 대제목에 붙었다 — 항목 · 글을 줄이거나 칸 높이를 한 단계 낮게 |
| 흰 도형이 하나도 없음 | 상자 없는 칸(`.bare`)에 흰 카드가 생기는 부품으로, 또는 칸에서 `.bare`를 뺀다 |
| 바로 앞 장과 같은 도식 · 같은 도식이 세 번째 | 이웃 장 부품과 다른 부품으로 바꾼다 |
| 보조 글 방식 … 세 번째 · 바로 앞 장과 같은 보조 글 | 다른 보조 글 방식으로 바꾸거나 보조 글을 뺀다 |
| 한 장에 도식이 …개 · 칸이 …개 | 칸을 하나로 합치고 나머지 말은 보조 글로 |
| 목록이 …줄 — 4줄까지 | 4줄로 줄이거나 두 장으로 |
| 큰 흰 상자는 표 · 가로 막대만 | 칸에 `bare`를 붙인다(`s-m w12 h2 bare`) |
| 글자 대비 … 안 읽힘 | 그 글을 메인 면 밖으로 옮기거나 `.accent`를 다른 칸으로 |
| 제목이 두 줄 | 대제목을 24자 안쪽으로 줄인다 |
| … 항목이 N개 — 예시 덱은 …개(빈약해 보임) | 항목을 예시 덱 개수만큼 늘리거나(지어내지 않는 선에서 — 방법 · 단계 이름은 설명하는 말이라 괜찮다), 늘릴 내용이 없으면 항목이 적어도 되는 다른 부품으로 |
| 사진 점검 문장('…해요 — 이렇게') | 그 줄의 '—' 뒤 방향대로 고친다. 부품을 바꾸라면 이웃 장과 다른 그림 도식으로 |
| 정렬 · 잉크 여백 문장 | 글을 줄이고 항목 수를 예와 같게 — 간격 · 크기는 키트가 맞추므로 `style`로 고치지 않는다 |

한 번 고친 뒤에도 같은 장이 또 걸리면, 홈페이지는 더 돌리지 않고 그대로 둔다(원장님이 스튜디오에서 마무리).
